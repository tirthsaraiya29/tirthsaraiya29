At a glance

A browser-based chat interface experiment for local AI models, with model selection, conversation handling, persona prompts and message rendering.

The problem

Local model experimentation often involves changing endpoints and model choices while losing continuity between conversations. Quantel explores a small interface around those everyday tasks.

Engineering approach

The repository contains a static HTML interface and a vanilla JavaScript client. It includes Markdown rendering and code highlighting, conversation state, model selection and persona/system-prompt controls, with a configured proxy path to a local model service.

What the project explores

  • Model selection and model descriptions
  • Chat message rendering and Markdown/code highlighting
  • Conversation list and persistent chat state
  • System persona prompt controls
  • Image attachment UI
  • Local-model proxy integration

Architecture at a glance

Static HTML/CSS interface → vanilla JavaScript state and request handling → local-model proxy → message rendering and browser-side persistence.

Engineering decisions

  • Use a static browser interface rather than a larger framework.
  • Keep Markdown rendering and syntax highlighting as separate libraries.
  • Make model and persona selection visible in the chat workflow.
Status and scope. Quantel is a prototype. The README is minimal and the implementation contains a configured endpoint that should be reviewed before deployment; this portfolio does not publish internal network details or claim a hosted service.
