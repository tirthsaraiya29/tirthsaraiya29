Tirth Saraiya

I'm a student software developer based in India, interested in how software works beneath the interface: operating-system boundaries, secure communication, local AI runtimes and the details that make applications dependable.

What I work on

My work spans systems programming, security engineering, local-first AI and application development. I move between low-level operating-system integration and user-facing applications, especially where a project needs careful engineering and a clear product experience.

Tether explores a phone-backed trust and workstation-control system across Windows, Linux and Android. Vantor is a Windows endpoint-security engineering project. Pico is a Rust desktop assistant built around intent retrieval, action policy and outcome verification. Whisk is an Android knowledge workspace with developer tools and an evolving local/cloud AI layer. Inferra explores hardware-aware model-fit estimation for local AI.

I also build browser-based experiments and contribute to open-source software beyond repositories I own. The public project catalogue records personal projects and upstream activity separately, with their status labelled clearly.
