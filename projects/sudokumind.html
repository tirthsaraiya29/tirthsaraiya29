At a glance

A Python tooling project focused on generating and independently validating high-quality Sudoku datasets, with uniqueness checks, logical difficulty traces and dataset-integrity controls.

The problem

A generated puzzle dataset is only useful when each puzzle is valid, uniquely solvable, correctly labelled and separated cleanly across training and evaluation splits. Naive generation can create duplicates, leakage or misleading difficulty labels.

Engineering approach

The documented generator uses a bounded exact solver, logical-strategy traces and calibrated difficulty scoring. A separate validator independently checks puzzle integrity, uniqueness, trace correctness and split leakage, with non-destructive repair and quarantine concepts.

What the project explores

  • Sudoku dataset generation and resumable processing
  • Bounded solution counting and uniqueness verification
  • Human-style strategy traces across graded deduction tiers
  • Difficulty calibration on a 1.0–10.0 scale
  • Cross-split duplicate/leakage prevention
  • Independent validation, repair and quarantine workflow

Architecture at a glance

Puzzle generation → exact solver and logical trace extraction → difficulty calibration → SQLite-backed deduplication/split registry → atomic dataset finalization → independent verifier/auditor.

Engineering decisions

  • Use bounded solution counting to distinguish unsolvable, unique, multiple-solution and unresolved cases.
  • Extract interpretable logical traces rather than relying only on a single numeric difficulty score.
  • Use canonicalization and hashes to prevent equivalent puzzles leaking across splits.
  • Keep validation independent from the generator to reduce correlated errors.
Status and scope. The README describes a four-part generator/verifier/trainer/evaluator architecture, but the visible top-level tree should be treated as the inspected scope. This page does not claim training quality, model accuracy or benchmark results.
