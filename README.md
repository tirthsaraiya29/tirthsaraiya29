## About

I'm Tirth, a student developer interested in the intersection of **systems software, security engineering, and local-first AI**.

I enjoy working across the stack: from native operating-system APIs and networking to mobile applications, developer tools, and intelligent automation. Most of my projects start with a question — *could this be faster, safer, more private, or better engineered?* — and turn into an attempt to build the answer.

- **Systems:** Linux, Windows, native integrations, services, IPC, and networking.
- **Security:** authentication, cryptography, endpoint protection concepts, and secure-by-design architecture.
- **AI & automation:** local inference, model tooling, decision systems, and developer agents.
- **Product engineering:** Android, desktop, and web applications with an emphasis on useful details.
