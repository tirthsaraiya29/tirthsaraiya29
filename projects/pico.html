At a glance

A local-first desktop assistant written in Rust. Instead of relying on a generative model to decide and execute everything, Pico explores retrieval, ranked intent candidates, explicit confirmations and outcome verification.

The problem

Voice assistants can sound convincing while misunderstanding intent or failing to carry out an action. A useful desktop assistant needs a reliable path from noisy input to a specific tool, with safe clarification when the decision is ambiguous and verification after execution.

Engineering approach

Pico separates audio capture, speech recognition, intent decision, orchestration, platform tools and security enforcement into Rust workspace crates. Its non-generative decision path retrieves candidate tools and ranks them before the orchestrator applies confirmation policy and verifies outcomes.

What the project explores

  • Non-generative intent and tool-retrieval pipeline
  • Candidate ranking and calibrated confidence mechanisms
  • Voice capture, VAD, resampling, speech recognition and multi-tier TTS
  • Windows and Linux native/system tools
  • Path sandboxing and SSRF protections
  • Session-scoped confirmations and outcome verification

Architecture at a glance

Microphone → audio pipeline / VAD → ASR and normalization → tool retrieval + candidate ranking → clarification / confirmation policy → platform tool execution → objective verification

Engineering decisions

  • Keep model-free deterministic tool selection as a first-class option rather than assuming an LLM is necessary.
  • Separate the headless runtime from the lightweight desktop companion.
  • Bind confirmations to the request, session, selected tool and argument digest.
  • Verify results before telling the user an operation succeeded.
Status and scope. Pico remains an active engineering project. Its voice quality, action reliability and desktop experience are still being refined. The architecture and capability list describe the system being built, not a guarantee that every tool or voice path is production-ready.
