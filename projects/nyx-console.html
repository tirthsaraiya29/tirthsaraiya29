At a glance

An atmospheric browser console for interacting with AI models, combining a chat workspace with streaming responses, session management and a visual interface inspired by a control-room dashboard.

The problem

A local-model interface can be more useful and enjoyable than a plain text box when it makes model state, conversation context and system activity easier to see.

Engineering approach

Nyx Console uses a single HTML entry point with CSS variables and vanilla JavaScript. A Three.js scene and DOM effects provide the visual layer while application code manages model selection, chat, persistence and request/response flow.

What the project explores

  • Chat with local models and streaming responses
  • Model and interaction-mode selection
  • Voice dictation where browser support exists
  • Conversation save, load, export and import
  • System event console and embedding visualization
  • Demo mode alongside local model endpoint integration

Architecture at a glance

Single HTML document → vanilla JavaScript application state → local model endpoint / proxy → streamed response and DOM updates; Three.js and CSS effects render the visual console.

Engineering decisions

  • Keep the project understandable with a small static web footprint.
  • Use CSS variables to centralize the visual system.
  • Separate the visual layer from the chat and session lifecycle.
  • Support reduced motion and accessible status updates alongside expressive animation.
Status and scope. This is an experiment rather than a production AI client. Local model endpoint availability and browser speech APIs depend on the user's environment. The repository README describes its intended capabilities.
