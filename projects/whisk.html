At a glance

A native Android knowledge workspace combining Markdown notes, links and graphs with developer-oriented surfaces and a local/cloud AI workspace.

The problem

Developer notes, project context, model tools and external repositories are often scattered across separate applications. Whisk aims to bring connected knowledge and practical developer workflows into one Android-native workspace without requiring every interaction to leave the device.

Engineering approach

Whisk is built with Kotlin and Jetpack Compose, using Room for durable local data and Android-native UI patterns. Its documented scope includes Markdown editing, wikilinks/backlinks, graph and canvas views, local model support, external model providers and an MCP client.

What the project explores

  • Markdown editor with rendered preview and code blocks
  • Wikilinks, backlinks and knowledge graph exploration
  • Spatial canvas for arranging notes
  • Local and hosted model integrations
  • GitHub exploration and Model Context Protocol client
  • Vault export/import with validation and path-safety handling

Architecture at a glance

Compose UI → domain/use-case layer → Room / DataStore persistence; AI workspace routes requests to local runtime or configured remote providers; MCP client mediates tool discovery and calls.

Engineering decisions

  • Keep the application Android-native rather than wrapping a web knowledge tool.
  • Use local persistence as the default workspace foundation.
  • Separate note-taking and graph operations from model-provider integrations.
  • Require approval for write or destructive MCP operations.
Status and scope. Whisk is actively evolving. The README's detailed description of its embedding path must be reconciled with the current provider implementation before claiming a particular semantic model or vector-search implementation as shipped. This page intentionally avoids promising semantic-search accuracy.
