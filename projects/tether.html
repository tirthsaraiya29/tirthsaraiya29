At a glance

A cross-platform personal trust system that pairs an Android device with a Windows or Linux workstation, using the phone as a cryptographic trust anchor for authentication and device-control workflows.

The problem

Workstation authentication is split across operating-system security boundaries. A phone can establish identity and user presence, but integrating that proof into a desktop logon flow means crossing privileged services, isolated sessions and native authentication APIs without quietly weakening them.

Engineering approach

Tether treats the phone as a paired identity device and keeps the core communication local to the network. Platform adapters connect Android to native Windows and Linux integration points, while trust, panic, recovery, pairing and enforcement responsibilities are separated into dedicated components.

What the project explores

  • Android companion and device pairing
  • Windows Credential Provider integration using native C++ / COM
  • Linux authentication integration through PAM
  • Local Wi-Fi/LAN communication with TLS 1.3 over direct TCP
  • Workstation lock, trust validation and emergency lockdown workflows
  • Separate services and session-aware helpers for platform integration

Architecture at a glance

Android companion → LAN discovery (mDNS / UDP) → authenticated TLS 1.3 session → platform communication service → session helper / native authentication adapter

Engineering decisions

  • Keep the core transport local rather than relying on a cloud relay.
  • Use native platform integration where authentication requires it instead of simulating a logon screen.
  • Separate privileged background services from interactive-session work.
  • Treat recovery and failure handling as first-class parts of the trust lifecycle.
Status and scope. Tether is in beta and actively changing. Its README explicitly warns that it has not received an independent security review and should not be relied on for mission-critical protection without one. The feature list describes project scope; availability can vary by platform and release.
